# CodeDock releases

Installers and the update manifest for **CodeDock**, a Windows desktop control center for local coding AI (Ollama + OpenCode).

This repository holds releases only — no source code.

- Download the latest installer from [Releases](../../releases/latest) (`CodeDock_<version>_x64-setup.exe`).
- Installed copies of CodeDock update themselves from here (Settings → Updates). Every update is signed; CodeDock verifies the signature against the public key built into the app and refuses anything else.
- The installer is not Authenticode code-signed yet, so Windows SmartScreen may warn on first install.
